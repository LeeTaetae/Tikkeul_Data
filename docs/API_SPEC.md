# API 명세

**현재 확정된 API는 없다.** 이 문서는 계약을 정할 때 채우는 틀이다. 아래 후보는 요구사항에서 도출한 제안이며 합의 전에는 구현하지 않는다.

백엔드: FastAPI + Pydantic. 요청·응답은 Pydantic 모델로 검증한다. FastAPI는 구현 후 자동 문서(`/docs`)를 제공하므로, 구현되면 그것을 정본으로 삼고 이 문서는 요약만 유지한다. (자동 문서 노출 설정은 TBD)

## 공통 규칙 (제안)

| 항목 | 내용 |
|---|---|
| 형식 | JSON, UTF-8 |
| 시각 | ISO 8601 (UTC 또는 오프셋 포함) |
| 갱신 시각 | 외부 데이터를 담은 응답은 `updated_at`을 포함한다 (F-07) |
| 에러 | 공통 에러 형식 TBD |
| 인증 | TBD |
| 버전 | TBD |

## 제약

- 카메라 원본 영상·프레임을 받는 API는 만들지 않는다.
- 위치 파라미터는 필요한 정밀도만 사용한다 (정밀도 TBD).
- 외부 교통 공공데이터 API의 요청·응답 형식은 선정 후 확인해서 기록한다 (TBD).

## 엔드포인트 문서 양식

엔드포인트가 확정되면 아래 양식으로 추가한다.

```
### <메서드> <경로>
- 요구사항: F-xx
- 요청: 파라미터 · 본문 (Pydantic 모델명)
- 응답: 상태 코드별 본문
- 에러: 코드 · 의미
- 비고: 갱신 시각, 캐시 등
```
