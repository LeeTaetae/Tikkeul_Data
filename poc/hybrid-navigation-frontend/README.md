# 카카오맵 차량 마커 애니메이션 PoC (실험 코드, MVP 범위 아님)

동료가 진행 중인 실제 앱(`frontend/app/map.tsx`) 작업과는 별개의 독립 실험 파일입니다. 7일 MVP 일정·앱 코드와 연결돼 있지 않습니다.

## 뭘 보여주는 PoC인가

카카오맵 JS SDK 위에서, GPS로 들어오는 위치·헤딩(방향각) 업데이트를 받아 차량 아이콘을 매 순간 스냅시키지 않고 `requestAnimationFrame`으로 부드럽게 이동·회전시키는 방법입니다. 핵심은 두 가지입니다.

1. 위치는 이전 좌표 → 새 좌표를 선형 보간
2. 회전각은 "최단 경로"로 보간해야 함 — 예를 들어 350도에서 10도로 돌 때 340도를 거쳐 돌면 안 되고 20도만 돌아야 함 (`shortestAngleDelta` 함수가 이 역할)

실제 GPS 연동 없이, 코드 안에 좌표 5개짜리 샘플 경로를 넣어 1.2초마다 다음 지점으로 애니메이션하는 걸로 동작을 확인할 수 있게 만들었습니다.

## 실행 방법

1. [Kakao Developers](https://developers.kakao.com)에서 JS 키 발급 후, 콘솔의 "플랫폼 > Web"에 이 파일을 서빙할 도메인(`http://localhost:5500` 등)을 등록합니다. `file://`로 그냥 열면 도메인 검증에 걸려 지도가 안 뜰 수 있습니다.
2. 이 폴더에서 간단한 로컬 서버를 띄웁니다: `npx serve .` 또는 `python3 -m http.server 5500`
3. 브라우저에서 `http://localhost:5500/vehicle-marker-demo.html?appkey=발급받은키` 로 접속합니다.

## 검증한 것 / 안 한 것

- `shortestAngleDelta` 함수는 파일 안에 `console.assert` 자가 테스트가 있어서, 브라우저 콘솔을 열면 경계값(350→10도, 10→350도)이 맞는지 바로 확인할 수 있습니다.
- 실제 카카오맵 렌더링은 유효한 JS 키 + 등록된 도메인이 있어야 눈으로 확인 가능합니다 — 이 세션에서는 키가 없어 실제 렌더링까지는 실행하지 못했습니다. 로직(보간·회전 정규화)만 자가 테스트로 검증했습니다.
